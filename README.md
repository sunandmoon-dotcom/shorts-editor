# 🎬 쇼츠 에디터 — 40초 세로(9:16) 웹 영상편집기

설치 없이 브라우저에서 바로 쓰는 쇼츠·릴스 전용 영상 편집기입니다.
PC(Chrome·Edge·Safari)와 아이폰(iOS Safari) 모두 지원하고, **서버·계정·백엔드 없이 100% 기기 안에서** 편집과 내보내기가 끝납니다.
정적 파일 3개(`index.html`, `style.css`, `app.js`)뿐이라 GitHub Pages에 그대로 올리면 됩니다.

---

## 빠른 시작

1. `index.html` 을 브라우저로 엽니다. (로컬 파일로 열어도 동작합니다)
2. **+ 영상** 을 눌러 MP4 · MOV · WebM 클립을 여러 개 불러옵니다.
3. 아래 순서로 다듬습니다 → **내보내기** → **MP4 다운로드**

### 아이폰에서
1. Safari로 페이지를 엽니다.
2. `+ 영상` → 사진 보관함에서 영상 선택 (또는 ‘파일’ 앱의 MP4)
3. 편집 후 **내보내기** → 완료되면 **MP4 다운로드** → ‘파일’ 앱에 저장
4. 인스타그램/유튜브 앱에서 그 파일을 업로드

> iOS는 17 이상 Safari를 권장합니다. 내보내는 동안 화면을 켜 두고 다른 앱으로 이동하지 마세요.

## 기능

### 기본 편집
| 기능 | 설명 |
|---|---|
| 멀티 클립 | 여러 영상 불러오기 · 위/아래 순서 변경 · 삭제 · 썸네일 표시 |
| 컷 편집 | 클립별 시작/끝 지점을 슬라이더·숫자로 조절, ‘현재 위치 = 시작/끝’ 버튼 |
| 9:16 맞추기 | 꽉 채우기(Cover) / 여백 + 블러 / 여백 + 단색, 좌우·상하 위치 미세 조정 |
| 자막 | 시간대별 여러 개 추가·수정·삭제, 크기·글자색·배경 박스·외곽선·위치(상/중/하) |
| 배경음악 | 오디오 파일 업로드, 원본 볼륨 / BGM 볼륨 분리, 페이드 인·아웃 |
| 배속 | 클립별 0.5x ~ 2x, 전체 배속 0.5x ~ 2x(곱연산) |

### 쇼츠·릴스 특화
- **40초 인디케이터** — 상단에 총 길이와 40초 게이지. 넘으면 경고 배지 + 알림.
- **세이프존 가이드** — 좋아요·댓글 아이콘/캡션 영역을 반투명으로 겹쳐 표시(미리보기 전용, 영상에는 안 들어감).
- **상단 후킹 제목** — 영상 전체 또는 초반 N초 동안 배지 형태로 표시.
- **색감 프리셋** — 원본 / 선명하게 / 따뜻하게 / 시원하게 / 흑백 / 시네마틱.
- **전환 효과** — 클립 사이 디졸브(길이 조절), 영상 시작·끝 페이드 인/아웃.

### 타임라인
클립 블록 + 자막 블록 + 재생 헤드를 한 줄에 표시. 클릭·드래그로 원하는 위치로 이동(스크럽)합니다.

## 내보내기 방식

```
Canvas(9:16) ── captureStream() ──┐
                                  ├─ MediaRecorder ── Blob ── .mp4 / .webm 다운로드
Web Audio (영상 + BGM) ─ MediaStreamDestination ─┘
```

- `MediaRecorder.isTypeSupported()` 로 **MP4(H.264+AAC) → MP4(H.264) → MP4 → WebM(VP9/VP8)** 순서로 지원 형식을 자동 선택합니다.
- 확장자와 파일명은 실제 녹화 형식에 맞춰 `.mp4` / `.webm` 으로 저장됩니다.
- iOS Safari의 오디오 정지 정책 때문에, **내보내기 버튼(사용자 제스처) 시점에 `AudioContext.resume()`** 을 호출합니다.
- 녹화는 실제 재생 속도로 진행됩니다(40초 영상 → 약 40초 소요). 진행률과 남은 시간이 모달에 표시되고 중단할 수 있습니다.
- 해상도 540 / 720 / 1080(9:16), 24·30fps 선택.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다(예: `shorts-editor`, Public).
2. 이 폴더의 파일 전체를 저장소 루트에 업로드합니다(최소 `index.html`, `style.css`, `app.js`).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/ (root)` → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/shorts-editor/` 에서 열립니다.
5. 아이폰 Safari에서 그 주소를 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

> 저장소 이름이 `<아이디>.github.io` 이면 주소는 `https://<아이디>.github.io/` 가 됩니다.

## 브라우저 요구사항

| 브라우저 | 지원 |
|---|---|
| Chrome / Edge (데스크톱) | ✅ MP4(H.264) 또는 WebM |
| Safari (macOS) | ✅ MP4(H.264/AAC) |
| Safari (iOS 17+) | ✅ MP4, 터치 UI |
| 구형 iOS(16 이하) | ⚠️ `MediaRecorder`/`captureStream` 지원이 제한적 |

## 알려진 제한

- **MOV(HEVC/H.265) 클립**은 브라우저가 디코딩하지 못하면 불러올 수 없습니다. 아이폰 ‘높은 효율성’ 촬영 영상은 ‘설정 → 카메라 → 포맷 → 호환성 우선’으로 바꾸거나 MP4(H.264)로 변환해 주세요.
- 내보내기는 **실시간 녹화**입니다. 탭을 백그라운드로 보내면 프레임이 끊길 수 있습니다.
- 40초를 넘겨도 내보낼 수 있지만(확인 창), 쇼츠·릴스에서는 잘릴 수 있습니다.
- 편집 상태는 저장되지 않습니다. 새로 고침하면 처음부터 시작합니다(내보낸 파일은 다운로드 폴더에 남습니다).
